# Aleksandra Jurkiewicz - to do list in React

## Simple to do list. 
### Instruction
1. Type new task content :)
2. Click on button "Dodaj zadanie".
3. Click on green button, if task is done. 
4. Click on red button, if you want to delete task.
5. Click on "Ukończ wszystkie", if all tasks are done.
6. Click on "Ukryj ukończone", if you want to hide done tasks.
7. Click on "Pokaż ukończone", if you want to see them again.
8. Type something in search to filter tasks.
9. Click on "Pobierz przykładowe zadania", if you want to download example tasks.
10. Click on "O autorze" if you want to read some informations about author.
11. Choose task and click on it to check if task is done.


### Used technologies
- JavaScript
- CSS
- HTML
- BEM
- React
- Redux
- Redux-Saga
- Redux-Router
- Redux-Toolkit
